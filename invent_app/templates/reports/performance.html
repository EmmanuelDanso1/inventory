⚡ Performance Comparison

Normalized vs Denormalized schema benchmark results

🗂 Normalized (3NF)

Data split across multiple tables. Uses foreign keys and JOINs. Better for data integrity.

✓ No duplication   ✓ Easy updates   ✗ Slower reads

📋 Denormalized

All data in one flat table. No JOINs required. Better for read-heavy reporting.

✓ Faster reads   ✓ Simpler queries   ✗ Data duplication

📊 Benchmark Info

Each query runs 10 iterations. Results show avg, min, max, std dev in milliseconds.

Lower ms = faster. Session cache cleared between iterations.
